# quantum-repeater-protocol-analysis-code-sidrc
Monte Carlo simulation framework for quantum repeater protocols with noisy memories. Compares distillation and swapping strategies (ASAP/ALAP timing) across single-link and double-link configurations. Analyzes fidelity dynamics, coherent information rates, and protocol performance across different memory coherence regimes.

Discard-Oldest.nb, Distill-ALAP.nb, and Distill-ASAP.nb contains Mathematica evaluations of the the protocol performances.
